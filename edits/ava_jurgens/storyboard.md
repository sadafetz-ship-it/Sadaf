# Ava Jurgens: editor-hiring reel storyboard (v1, not built yet)

**Source:** a single continuous talking-head shot. 1080×1920, 30 fps, 41.0 s, warm room background, black hoodie.
**Style:** house style (`video-motion-study`). This project uses the green palette from the circled swatches instead of the default purple.
**Preview board:** `board_v1.jpg`. Full-size frames are in `preview_v1/f01–f10.jpg`.

## Palette (sampled from the circled swatches)
| Token | Hex | Use |
|---|---|---|
| Neon lime | `#B8FF37` | main accent: glows, lines, pixel clusters, dot after heavy words, buttons, checkmarks |
| Pale green | `#D8FF92` | script word, highlights, card borders, pill text, "active" rows |
| White | `#FFFFFF` | all main text, the line-1 caption |
| Deep green | `#17200D` | explainer backgrounds, card bodies, bottom grade |
| Muted olive | `#7A963F` | atmospheric glow pools, empty tracks, gradient starts, soft-light tint over footage |

The house style uses a rose dot and blue/magenta details. Here the dot after heavy words is **lime**, and there are no off-palette details.
"Golden Hour" glow in green: fill `#FFF → #F4FFE0 → #E2FFAE → #D8FF92`, glow `#D8FF92 / #B8FF37 / #7A963F`.

## Global rules
- Captions are always on: a lower-third three-line lockup (Inter Display Light setup line, Allura script accent, Inter Display SemiBold heavy word with a lime dot). Each word appears on its spoken frame. Every heavy word gets a **Scripts pixel reveal** in lime/pale tones.
- The mode changes every 1.3–2.5 s: caption only, name behind head, card on chest, or full-background explainer.
- **Camera:** slow push-in on each talking stretch, a 4 f punch-in on key words, and a zoom-blur on every switch between talk and explainer.
- **Sound:** riser → whoosh → impact on every screen change. One soft click per caption. The Scripts hit plays on bold words only.
- The edit ends on the CTA with a short fade. There is no recap board.
