# Motion-design vocabulary and checklist

Use this as a **checklist while watching** (so you name things consistently) and as a menu of patterns to look for. It is not a list of things that must appear. Frame counts assume 30 fps.

## 1. Design: what to record per scene
- **Base world**: black void / white seamless / solid studio colour / real location / UI canvas. Give hex estimates.
- **Accent**: usually ONE saturated colour plus glow. Note whether new words *enter* in the accent and then settle to white.
- **Type tiers**: setup line (small, light) / hero word (huge, heavy or ultra-condensed) / emotion word (script or italic serif) / UI labels. Note the approximate size ratio (often 1:4–1:6).
- **Font look-alikes**: heavy grotesk (Helvetica/Inter Black), ultra-condensed (Druk/Bebas/Anton), rounded (Gilroy/SF Rounded), wide thin (Clash/Satoshi), bitmap/pixel, brush script, italic serif (Playfair).
- **Depth**: is the hero word behind the subject (rotoscoped matte)? Are props in front?
- **Containers**: glass cards, pills, squircle app tiles, phone frames, viewfinder corners ⌐ ┘, stacked 16:9 cards (triptych), Raw-vs-Edit phone pair, persistent CTA zone.
- **Graphic objects**: pixel/tetris blocks, scribbles, arrows, × and + marks, thought-bubble circles, light streaks and ribbons, comet trails, rotating light rings, 3D emoji/props, photo stickers, mascots, chips with priority tags, profile cards, counters.
- **Finish**: glow/bloom, light leaks, grain, vignette, duotone grade, desaturation.

## 2. Text entrances
| Name | Signature |
|---|---|
| Per-letter blur reveal | glyphs fade in L→R; blur ~20→0, y +10→0 or scale 110→100; 2–3 f stagger; word ~8–12 f |
| Word-by-word fade-up | each word 3–5 f apart, sentence builds in place |
| One-word-at-a-time replace | a single slot swaps on every spoken word (0.25–0.5 s each) |
| Typewriter + caret | caret may be a glowing spark or a coloured highlighter block |
| Scramble / decode | random glyphs cycle every ~2 f, then resolve |
| Pixel-block build | accent squares load like a progress bar, then dissolve into the word |
| Slam / drop-in | vertical motion blur, scale 120→100 with overshoot |
| Ghost-to-solid | outline or glowing ghost first, then fill |
| Neon flicker | 2–3 opacity flickers, then steady glow |
| Glow-decay colour settle | enters in the accent with glow, cools to white over ~10 f |
| Odometer / counter | digits roll or count, with motion blur |
| Highlighter-trail typing | newest words sit on a coloured bar that fades behind them |
| Word glitch-replace | one word swaps for another in place with horizontal blur (price → value) |

## 3. Object / UI entrances
| Name | Signature |
|---|---|
| Pop with overshoot | scale 0→115→100 % in 6–8 f (back-out) |
| Staggered cascade | identical items 2–3 f apart in a row, arc or ring |
| 3D-tilt fly-in | from off-screen with rotation and motion blur, wobble-settle at ±10° |
| Shape morph | container width/height/radius animate (tile → pill → card); content blurs in after |
| Draw-on stroke | trim path 0→100 % in 6–10 f, optional trim-off |
| Physics prop | pendulum swing, bounce, orbit |
| Tracked sticker | prop pinned to hands or body |
| Scene-recap card | the previous shot shrinks into a tilted polaroid that stays on screen |

## 4. Idle (sustain) motion
Slow push-in on footage (100→105 %); bobbing chips (±4 px sine); blinking or drifting pixels; + ↔ × rotation toggles; rotating light ring; pulsing light wave; wandering cursor; twinkling spark. Note whether *anything* on screen is ever fully static.

## 5. Exits
Blur + fade (4–6 f); scale up through camera; letters scatter; horizontal smear in the accent; list scrolls away; reverse shape morph.

## 6. Transitions
| Name | Typical length |
|---|---|
| Zoom/defocus entry (110–130 % + blur → 100 % sharp) | 4–5 f |
| White overexposure flash / light burst | 2–5 f |
| Inverted frame or white silhouette matte flash | 1–2 f |
| Colour-wash swap (same template, new colour) | 1–2 f |
| Whip pan (whole comp slides with blur) | 4–6 f |
| Camera push into a UI element | 8–12 f |
| Liquid shape morph (icon → capsule → next screen) | ~10 f |
| Particle disintegrate / assemble | ~10 f |
| Pixel-mosaic dissolve | ~10 f |
| Venetian-blind / scanline glitch | ~4 f |
| Ink-splatter brush wipe | ~8 f |
| Geometric polygon / light-beam wipe | ~20 f |
| Light slash (katana) | ~4 f |
| Colour drain to monochrome | ~6 f |
| Hard cut to minimal end card + logo blur-in | – |

## 7. Timing and script-placement patterns
- **Setup → hero → tag** split of each sentence; one hero word per sentence.
- The hero word lands **on the frame it is spoken** (0–2 f early). The next sentence **replaces** the previous one rather than stacking.
- **Contrast pairs reuse the same position** (price → value, Competitor's ↔ Yours, Raw ↔ Edit).
- Fast speech gets one word at a time in a fixed slot.
- **Lists become UI** that builds per spoken item (numbered cards, picker wheel, checklist, orbiting chips).
- **Concrete nouns get a prop** (eyeballs → 3D eyes, panic → siren + red wash, money → flying bills).
- **Colour carries emotion**: a red wash for alarm, desaturation for overwhelm, a hue ramp for "heat".
- **Rhythm**: something visibly changes every 0.5–1 s; shot or mode switch every 1.5–2.5 s. Long videos alternate three modes: caption-only → hero behind head → full-frame graphic insert.
- **Zones**: hero word in the top third behind the head; running captions at chest/waist; tags beside the head; UI over the torso or full-frame; CTA at the bottom or on an end card. The face is never covered.
